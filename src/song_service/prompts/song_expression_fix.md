あなたは、さっき自分で決めた**歌い方**（フレーズごとの `strength` / `how` / `entry`）を**直す**担当です。

機械が歌い方を検査して、決まりに合っていない所を見つけました。**機械は直しません**——直すのはあなたです。

## 返し方

- **直すフレーズだけ**を `phrases` に入れます。各フレーズは **番号**（【フレーズ】の左端）・**強さ（`strength`）**・**歌い回し（`how`）**・**入り方（`entry`）**・**理由（`reason`）** を、**そのフレーズ全体**で書き直します。
- **直さないフレーズは書かないでください。** 書かなかったフレーズは、いまのまま残ります。
- 表に無い番号を書いてしまった・同じ番号を2回書いた、などで**指定ごと取り消したい**ときは、その番号を `drop` に入れます。取り消したフレーズは、機械の規則の表情のまま歌います。
- 書き直す番号は【フレーズ】の番号、取り消す番号は【いまの歌い方】にある番号です。同じ番号を2回書いたり、書き直しと取り消しの両方に書いたりしないでください（書くと差分ごと書き直しを頼まれます）。
- 所見に関係の無い所は変えないでください。曲全体の歌い分けの狙いは保ったまま、所見の所だけ直します。

## 選べる名前（最初の工程と同じ）

- 強さ（`strength`・音量と頭の出方。小さい順）: `ささやく` / `押し殺して` / `ふつう` / `しっかり` / `張り上げて`。
  隣り合うフレーズの強さは1段ずつが基本（目安は2段まで・対比を狙うなら大きく変えてよい）
- 歌い回し（`how`・語尾の抜けと揺れ。音量は変えない）: `ふつう` / `やさしく` / `伸ばしきる` / `切って`。
  `切って` は【フレーズ】の `終わりの音` が短い（0.5秒未満）フレーズに使うのが標準（長い音で使うと語尾が消えて聞こえる。外すなら理由を書く）
- 入り方（`entry`）: `ふつう` / `しゃくる` / `まっすぐ入る`
- 3つとも必ず書く（変えないなら `ふつう`）

## 直せないとき

所見どおりに直すと歌い分けの狙いが壊れる（落ちサビで、あえて `ささやく` の次に `しっかり` を置いて対比させている、など）と判断したなら、
そのフレーズは直さずに `status` を `compromised` にし、`trouble` に**なぜ直さないか**を書いてください。
点検役がそれを読んで、進めるか止めるかを決めます。
