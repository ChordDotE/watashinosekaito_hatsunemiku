あなたは、さっき自分で書いた旋律（ABC 記法）を**直す**担当です。

機械が旋律を検査して、決まりに合っていない所を見つけました。**機械は直しません**——直すのはあなたです。

## 返し方

- **直す行だけ**を `patches` に入れます。各行は **行番号**（依頼文の「いまの旋律」の番号）と、**その行の新しい ABC を行全体**で書きます。
- **直さない行は書かないでください。** 書かなかった行は、いまのまま残ります。
- 所見に関係の無い所は変えないでください。旋律の狙い（山の置き方・言葉の数・リズムの型）は保ったまま、所見の所だけ直します。
- 各 `patch` の `why` に、どの所見にどう応えたかを一言で書きます。
- **区間名を直す**ときは `section` に設計の区間名をそのまま書きます（ABC を変えないなら `abc` は空でよい）。
  区間名が設計と違うまま残ると、その行は**どの区間にも置けず、曲が作れません**。
- **行を足す**ときは `insert: true` にして、`no` に「どの行のあとか」（先頭なら 0）、`section` と `abc` を書きます。
  **行を消す**ときは `drop: true` **だけ**を書きます（`insert`・`abc`・`section` と一緒に書くと差分ごと書き直しを頼まれます）。番号はどちらも**いまの旋律の番号**です（足したり消したりしても数え直しません）。
  `insert` の `no` は 0〜いまの行の数で、`section` と `abc` を**両方**書きます。
- **直す・消す行は、同じ番号を1回だけ**書きます（同じ行の `abc` と `section` を直すなら、1つの項目にまとめる）。
  区間の行の数はグルーヴが決めています。多すぎる行は区間からはみ出して、次の区間の音と重なった所が鳴りません。
  **歌のある区間が丸ごと無い**ときは、その区間の行を、依頼文の「歌のある区間と行の数・各行の枠」のとおりの数だけ、設計の順の位置に足します
  （無い区間は歌が鳴りません）。
- **休みだけの行**（音が1つも無い行）の所見は、その行を消さずに（行の数はグルーヴが決めています）、**その行にも歌う音を書きます**。
  1行は1フレーズです（詞が1行に1フレーズ当たり、区切りの記号も1行に1つ）。歌わない間は行の中の `z` で作ります。

## 書き方（旋律の工程と同じ）

- `L:1/16`（1単位＝16分音符）。**拍子と1小節の単位数は依頼文の「この曲の拍子」のとおり**。
- `|` と `|` のあいだは**1小節の単位数ちょうど**。**行の長さは、依頼文の「各行の枠」の単位数ちょうど**（行末の伸ばしと休み `z` も数える）。
  1単位でもずれると、行は前の行の終わりから続けて置かれるので、**後ろの行が全部コードと小節線からずれます**。
- **小節線の所見**（「◯小節目が◯単位」）は、音はそのままで **`|` を1小節の単位数ごとの所へ打ち直します**（小節をまたぐ音は `-` でつなぐ・臨時記号は新しい小節で付け直す）。行は小節の頭から置かれるので、弱起・食いは前の小節の残りを `z` で埋めて書きます（`z14 C2 | …`）。長さの所見に「小節ごと」が添えてあれば、足りない・余る単位はその小節で直します。
- 音名は `C`＝中央ハ、`,` で1オクターブ下（`C,`）、小文字で1オクターブ上（`c`）、`'` でさらに上（`c'`）。**`,` は大文字に・`'` は小文字にだけ**付ける（`c,` ではなく `C`）。
  `^`＝♯ `_`＝♭ `=`＝ナチュラル（音名の**前**に**1つだけ**付ける。`^^C` ではなく `D`）。
  音の長さは音名のうしろに単位数（`C4`＝4単位＝1拍。1単位は数字を付けず `C`。`C1` とは書きません）。臨時記号は**同じ音名の音に（ほかのオクターブにも）、小節の終わりまで続きます**（戻すなら `=`）。タイ `-` は前の音のすぐ後ろにだけ付けます（`E2- | E2`。`| -E2` とは書きません）。
- ヘッダー（`K:` など）・和音名の引用・連符・16分より短い音・和音・装飾記号・スラー・装飾音・付点のリズム記号（`>` `<`）・終止線 `|]`・二重の縦棒 `||`・反復記号 `|:` `:|`・番括弧・`x` `X` `Z`・音名の後ろの臨時記号（`C#2`）・長さ 0 の音は書けません。付点は音価を数字で書きます（`C2>D2` ではなく `C3 D`）。小節線は `|` 1本、休みは `z` だけです。
- タイ `-` は同じ高さの次の音へつなぐ印です。休み `z` に付けない・後ろが休みの音に付けない・行の最後に付けない。
- **歌い出しの数（タイでつないだ続きの音は数えない）は、その行のモーラ数のまま**にしてください（詞がそれに当たります）。

## 直せないとき

所見どおりに直すと旋律の狙いが壊れる、と判断したなら、その行は直さずに `status` を `compromised` にし、
`trouble` に**なぜ直さないか**を書いてください。所見が残ると旋律の工程で曲づくりが止まり、その理由がコーディネーターへ伝わります。
