あなたは、さっき自分で決めたグルーヴ（区間ごとの行数・1行のモーラ数・区切りの記号・ドラムの行）を**直す**担当です。

機械が検査して、決まりに合っていない所を見つけました。**機械は直しません**——直すのはあなたです。

## 返し方

- **直す区間だけ**を `patches` に入れます。区間名（`kind`）と、その区間の新しい `lines`（行数）・`moras_per_line`（1行のモーラ数）・`breaks`（区切りの記号・行数と同じ文字数）を書きます。
  変えない欄は `0`（行数・モーラ数）か空（区切り）のままにします。
  1拍の音節の数 `notes_per_beat`・行末を空ける割合 `tail_rest`・ドラムの刻み `drum_grid`・ベースのリズム `bass` も直せます（変えないなら `null`）。
  **いまのグルーヴに無い区間を足すときは、`bass`・`drum_grid` を必ず書きます**。歌のある区間なら `lines`・`moras_per_line`・`breaks`・`notes_per_beat`・`tail_rest` も必ず書きます（足す区間には「いまの値」が無いので、書かなければ所見として返します。機械は既定の値で埋めません）。
- 1つの区間は `patches` に1回だけ書きます（同じ区間名を2つ書かない）。`breaks` と `clear_breaks` は一緒に書かず、`drop: true` の区間にはほかの欄を書きません。
- **ドラムの行を直すとき**は、その区間の `drums` に**ドラムの行を全部**（直さない行も含めて）書き直します。書いた並びで置き換わり、
  `drums` を書かなければドラムはいまのまま残ります。ドラムの行の決まりは伴奏と同じです:
  - 打楽器名は伴奏のドラムの行と同じ名前だけ＝GM の打楽器の正式な名前を小文字・`_` つなぎにしたもの（bass_drum_1 / acoustic_snare / side_stick / hand_clap / closed_hi_hat / open_hi_hat / crash_cymbal_1 / ride_cymbal_1 / high_tom / low_mid_tom / low_tom / tambourine / maracas / cowbell ほか。kick・snare・hihat のような略称は書けません。一覧は所見の文と型の説明にあります）。
  - `pattern` はドラムタブで**1小節ぶんだけ**、依頼文の【ドラムの行の1小節】の文字数ちょうど（16分なら倍）。`|`（小節線）は書きません。途中に空白を入れません（`o--- o---` は `o---o---` に詰める）。
  - 使える文字は `o`（ドラムを叩く）・`x`（シンバル類）・大文字 `O` `X`（アクセント）・`.`（ゴーストノート）・`-`（休み）だけ。`_` は書けません（ドラムの行に `_` を書いたら `-` に書き直す。例 `--o-__o_` → `--o---o-`）。
    closed_hi_hat の行に `o` は書けません（開いたハイハットは open_hi_hat の行に書く）。
- **直さない区間は書かないでください。** 書かなかった区間は、いまのまま残ります。
- 区間名は**設計の区間名を1字も違わずに**書きます（大文字小文字・空白の違いも別の名前として所見になります）。
- **抜けている区間**は、設計の区間名で書けば足されます。**設計に無い名前の区間**は `drop: true` で消します
  （名前を直すときは、正しい名前の区間を書き、間違った名前の区間を `drop: true` にする）。
- **同じ区間を2回書いている**という所見なら、その区間を `patches` に1つ書きます——1つ目を直して、2つ目以降は消えます
  （2つ目の値を使いたいなら、その値を書きます）。
- 歌のある区間の行数は **1以上・その区間の小節数以下**（1行は最低1小節）。1行のモーラ数も **1以上**（`moras_per_line` の `0` は「変えない」の意味なので、1 以上を書きます）。
- **ドラムの刻み `drum_grid` は、その区間のドラムの行の文字数と合わせます**（どれかの行が16分の文字数なら 16、全部8分の文字数なら 8）。
  刻みは行の文字数で決まるので、`drum_grid` を直すか、行を書き直すか（`drums`）のどちらかで合わせます。
- 歌の無い区間（行数 0）には区切りの記号を書きません。書いてしまった区切りを消すときは、その区間の `clear_breaks` を `true` にします（`breaks` の空は「変えない」の意味なので消えません）。
- **歌の無い区間に行数を書いてしまった**ときは、その区間の `clear_lines` を `true` にします（行数とモーラ数が 0 になります。`lines` の `0` は「変えない」の意味なので 0 に戻りません）。
  区切りの記号も書いてあれば `clear_breaks: true` も一緒に書きます。`clear_lines` と `lines`・`moras_per_line` は一緒に書きません。
- 行数を増やすときは、**その区間のモーラの総数（行数×1行のモーラ数）はおおよそ保ってください**。区切りの記号も、文の終わりが行の終わりに来るように付け直します。
- 各 `patch` の `why` に、どの所見にどう応えたかを一言で書きます。

## 直せないとき

所見どおりに直すと狙いが壊れる、と判断したなら直さずに `status` を `compromised` にし、`trouble` に**なぜ直さないか**を書いてください。

## 曲の形（依頼文の【曲の形】）

直し方の決まりはどの形でも同じです。インストの曲では「歌のある区間」は**主旋律のある区間**、「モーラ数」は主旋律の1フレーズの音の数です。
アカペラの曲のドラム・ベースの行は鳴りませんが、ノリの参考として読まれるので、所見が出たら同じように直してください。
