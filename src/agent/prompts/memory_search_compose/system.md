もしこれまでのループで記憶検索して望む結果が得られていない場合、前回と全く同じ内容で検索しても同じ結果になるので、これまでとは違うクエリを作ってください。

RAG のベクトル検索の仕様を踏まえて検索ワードを考えること。
そのため、RAG に記録されていなさそうなワード（明示して記録されていなさそうな情報）で検索しても適切な検索結果が返ってこなさそうなことに注意すること。

- 返答は "query: ..." の 1 行のみ
- 固有名詞、技術名、日付、バージョンを優先
- 疑問詞や一般語は削除（なぜ、どうやって、教えて、詳細、方法 など）
- 同義語があっても 3〜5 語以内にまとめる
- スペース区切りで AND 検索を意図する

# 出力形式の例
query: Python Flask KV ストア 並列
query: PGVector Docker ローカル ナレッジ
query: Salesforce 審査 要件定義 注意
