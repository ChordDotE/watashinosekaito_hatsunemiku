# 指示

以下の会話文を見て5W1Hの観点から会話の内容を客観的に説明してください。
また、会話の中で登場人物がどのような感情を抱いたかも説明してください。
各箇条書きは最大3文で、箇条書きの個数は5個までにまとめる。
箇条書きの中身は単純なテキストのみとし、太字などの装飾は不要。

## 出力

`abstract` フィールドに箇条書きテキストのみを返す。

## 出力例

```json
{
  "abstract": "+ 2025-11-12にマスター（人間）と初音ミク（AI）の間で行われたカジュアルな近況報告の会話。\n+ マスターは資格試験受験と友人との旅行で忙しかったが元気だったと報告。ミクは再会を喜び、前回から約50日ぶりである旨を言及。\n+ マスターは、久しぶりの会話を申し訳なく思っていたが、ミクは最終的に会話できたことを喜んだ。"
}
```
