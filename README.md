## 第1章: 一般ユーザー向けガイド 👥

### 🎯 このシステムについて

**「初音ミクと一緒に暮らそう！」**

このシステムは、初音ミクの声と姿でリアルタイムに会話できるアプリケーションです。
その場かぎりのQ&Aではなく、過去の会話を覚えていて、放っておくと向こうから
話しかけてくれる「一緒に過ごす存在」を目指しています。

#### ✨ 主な機能

**🗣 話す・聞く**

- **初音ミクの声で応答**: 文章を作りながら同時に声にするので、待たされません
- **声で話しかけられる**: マイクの音声認識＋自動送信で、手を使わず会話できます
    - 話し方（声の調子や間）から「言い終わったか」を聞き分けて、すぐ返事が始まります
    - **ミクが考えている間に続けて話しかけても、まとめて踏まえて返事してくれます**
- **字幕モード**: 返答を画面下部の字幕で表示し、音声と口の動きを止めます（音が出せない環境向け）
    - 入力欄の横にある字幕ボタンで ON / OFF
- **ファイルを見せて話せる**: 画像・音声・動画を送って、それについて話せます
    - 動画は送信前にブラウザで自動圧縮（対応ブラウザ: Chrome / Edge 系）
- **カメラで見せられる**: カメラに写したものについて話せます
    - カメラが ON のあいだは、ミクがあなたの顔の方を向きます（表示メニューの目のボタンで ON / OFF）

**🧠 覚える・思い出す**

- **会話を覚えている**: 過去の会話を踏まえて話します。日をまたいでも続きから話せます
- **昔のことを思い出す**: 特定の話題を探すだけでなく、**ふと昔のことを思い出して**話題にします
- **自分用のメモを持つ**: 気づいたことや「今度やりたいこと」を自分で書き留めます
- **あなたを見分ける**: **あなたの顔と声を覚えて**、話しかけてきたのがあなたかどうかを判断します
    - 見分けられるのは、登録したあなた1人かどうかだけです（ほかの人どうしは区別しません）
    - 登録は、ミクに「顔を覚えて」と頼んで写真を見せる（カメラか画像の添付）、「声を覚えて」と頼んであなたの声だけを10秒ほど録った音声ファイルを添付する、のようにします

**🌱 自分から動く**

- **自分から話しかけてくる**: しばらく無言だと声をかけてくれます。時間帯に応じた気遣いも
- **世の中の話題を眺める**: ニュースやブログの見出しを見て、気になったことを覚えておきます
    - どんな分野を眺めるかは「設定」タブで選べます
- **調べものをする**: 知らないことや最新のことは、自分で検索して確かめます
    - Tavily の APIキー（任意）を入れると、調べもの用の検索が使えるようになります。入れなくても、じっくり考えるときに Gemini の Google 検索を使うことがあります
- **気持ちと興味を持つ**: いいことがあるとしばらく機嫌がよく、気になったことは自分で調べにいきます
    - 気持ちも興味も、時間とともに薄れていきます
- **メールで知らせる**（任意機能）: 離れているときに、ミクからメールを送れます
    - 送信元の Gmail アドレス・そのアプリパスワード・受け取るアドレスの3つを「設定」タブで入れると使えます

**🎭 姿と声**

- **Live2D アバター**: 口の動き（リップシンク）・表情・相づちなどのモーションつき
- **声の調子が変わる**: そのときの気持ちに合わせて、話す速さ・声の明るさ・大きさが変わります
    - 「設定」タブで止めることもできます

**🎼 曲を作る・歌う**（任意機能）

- **曲を作る**: ミクが曲を作り、**歌声の書き出しまで自分でやります**
    - **VOCALOID6 ＋ 初音ミク V6（別売・有償）が要ります。**無い環境では導入できません（歌声にできないと、ミクに歌ってもらえないため）。詳細は [install_steps.md](install_steps.md)
    - ここで鳴るのは**本物の初音ミクの歌声**です。似せた合成音ではありません。動かすために必要というだけでなく、**この声を生み出した方々への敬意として、ぜひ購入して使ってみてください**
    - **オリジナル曲**: GPU は不要（追加約4GB・十数分。うち約3GBは歌声の聞き取り用）。テーマ→設計→コード（和音）→旋律→詞→編成→伴奏の工程で1曲ずつ作り、区間ごとに楽器と弾き方を変えます
        - **歌もの・アカペラ（声だけ）・インスト（歌なし）**の3つの形で作れます。できたあとで「アカペラにして」のように形を変えることもできます
        - 曲名は、詞まで書き終えてからミクが曲に合わせて決めます
        - ミクは作りながら自分で曲を見直し、気になった所はその工程に戻って直してから仕上げます。仕上げの前にも曲全体をもう一度見直します（あとから大きめの直しを頼んだときも、書き出す前に見直します）
        - 2回直しても納得できなければ、「まだできていない」と伝えて止まります（そこまで作った分は残り、続きから作れます）
    - **カバー（既存曲の再現）**: 楽譜（MIDI）が見つかる曲なら GPU 無しで作れます
        - 見つからず**音源から採る場合だけ NVIDIA GPU** が要ります（ディスクの空き約30GB・ダウンロード約15GB）。音を分ける・採譜する・声と歌詞を合わせる処理に使うためです
        - GPU が無くて音源からしか作れない曲は、ミクが「原曲そのままは無理だけど、雰囲気を汲んで新しく作るのはどう？」と提案します
        - ※**お手本の楽譜・音源・歌詞をインターネットで自動的に探してダウンロードします**（検索に DuckDuckGo・Google 検索〔Gemini 経由〕・Tavily〔キーがある場合〕を使います）。できた曲を公開・配信する場合の権利の確認は、ご自身でお願いします（[セキュリティ・プライバシー](#-セキュリティプライバシー)）
- **できた曲を歌ってくれる**: 「あの曲うたって」と頼むと、画面で歌います（口も動きます。インストは歌わずに流します）

**📱 どこからでも**

- **PC・スマートフォンから使えます**。どの端末から入っても、**同じミク**と話せます
- **外出先からも**アクセスできます（設定が必要。[セキュリティ・プライバシー](#-セキュリティプライバシー)をお読みください）

#### 🔍 機能の特徴

**🎭 一貫したキャラクター体験**
- どの端末でアクセスしても、起動したPC上の、同じ初音ミクと会話します
- 会話・記憶の保存はすべてあなたのPCの中（考える・話す・聞き取るにはクラウドを使います）。**あなたのミクは、あなたの端末に住んでいます**
- 見分けられるのは、話しかけてきたのが登録したあなたかどうかだけです。ほかの人どうしは区別しないので、複数人で話すときは文字入力欄に誰の発言かを書き添えてください

**🎵 高品質な音声体験**
- 返事の文章を作りながら、できたところから声にして流すので、待ち時間が短くて済みます
- ミクが話している間も次の入力ができます。ミクが考えている間は、姿の右上で印が回ります

**⏰ 自然な会話リズム**
- 話し終わりを察知してすぐ返事（決まった秒数を待ちません）
- ミクが考えている間もマイクは開いていて、追加の発話を時系列で受け取ります
- しばらくあなたからの返事がないとミクから話しかけてくれます

### 🛠️ 必要なもの

#### ⭐ おすすめの構成（まずはこれだけ）

**この5つだけ用意すれば、ミクと会話できます。GPU は要りません。**

| # | 用意するもの | 備考 |
|---|---|---|
| 1 | **Windows 11（64bit）とインターネット接続** | GPU は不要です。ディスクの空きは**約11GB**（作曲機能は下の「追加で使えるもの」のぶんが別に要ります）|
| 2 | **Google AI Studio の APIキー** | ミクの頭脳。取り方は[この下](#-apiキーの取り方必須の2つ) |
| 3 | **Fish Audio の APIキー** | ミクの声と、あなたの声の聞き取り。同上 |
| 4 | **Live2D Cubism SDK for Web**（zip のまま）| ミクの姿。https://www.live2d.com/sdk/download/web/ |
| 5 | **Live2D 初音ミクモデル Pro版**（zip のまま）| 同上。https://www.live2d.com/learn/sample/ |

> ⚠️ **4と5はこちらから配れません**（ライセンス上、再配布できないため）。お手数ですが
> ご自身でダウンロードしてください。**展開・配置・ビルドはセットアップツールが自動で行います**
> （zip の置き場所を選ぶダイアログが出ます）。
>
> ⚠️ **2・3・4・5 はインストーラが必須として求めます**（未入力では先へ進めません）。
> 会話・声・姿に直結するもので、無いまま入れても動かないためです。

> 💡 **Python と Node.js の手動インストールは不要です**: セットアップツールが Python を
> 自動取得し（uv）、Node.js も必要時に自動インストール（winget）します。

#### 追加で使えるもの（いらなければ飛ばしてください）

**どれも後から足せます。**入れなくてもミクとの会話には影響しません。

| 使いたい機能 | 追加で要るもの |
|---|---|
| **曲づくり（オリジナル曲）** | **VOCALOID6 ＋ 初音ミク V6**（別売・有償）。ディスク約4GB。**GPU は不要** |
| **曲づくり（カバー・楽譜が見つからない曲）** | 上に加えて **NVIDIA GPU**（CUDA対応）。ディスクの空きは作曲機能全体で約30GB（ダウンロード約15GB）。音源から採譜するため |
| **ミクが調べものをする（Web検索）** | **Tavily の APIキー**（https://tavily.com/ ）。後から「設定」タブで入れると有効になります |
| **ミクがメールを送る** | **送信元の Gmail アドレスとそのアプリパスワード**、受け取るアドレス（詳細は [install_steps.md](install_steps.md)）|

> ⚠️ **カバーを音源から作るとき（GPU を使う処理）の注意**: ゲームや動画編集ソフトなど、
> 他に GPU を使うアプリと同時に動かすと、大幅に遅くなったり、途中で止まることがあります。

#### 🔑 APIキーの取り方（必須の2つ）

**インストーラの途中で入力を求められます。**先に取っておくとスムーズですが、
インストーラを開いたまま取りに行っても大丈夫です。
**どちらも、クレジットカード等の支払い方法を登録したうえでキーを発行してください。**

**① Google AI Studio のキー（ミクの頭脳・必須）**

1. https://aistudio.google.com/apikey を開き、Google アカウントでログインします
2. 利用規約に同意すると、**プロジェクトとAPIキーが自動で作られます**。表示されたキーをコピーします
3. キーが作られない場合は、**すでに Google Cloud を使っている**ケースです。左の「ダッシュボード」→
   「プロジェクト」→**「プロジェクトをインポート」**で使うプロジェクトを取り込んでから、
   「APIキー」ページで作成してください

> 💡 キーは `AIza…` で始まる長い文字列です。
>
> 💴 **支払い方法を登録し、前払いのクレジットを購入してください**（最低 $5。**$10 ほど入れておくと
> 落ち着いて使えます**）。**残高が尽きるとミクは黙ります**ので、「お支払い」ページの
> **オートチャージ**を設定しておくと安心です（月あたりの上限も決められます）。

**② Fish Audio のキー（ミクの声・必須）**

1. https://fish.audio/auth/signup でアカウントを作り、メールのリンクで認証します
2. ログインしたまま https://fish.audio/app/api-keys を開きます
3. **「Create New Key」**を押し、名前を付けて作成し、表示されたキーをコピーします
   （キーは**作成直後にしか表示されません**。コピーし忘れたら作り直してください）

> 💡 **月額プランへの加入は不要です**（サイト上の Plus 等は、Fish Audio の**Webサイトで**音声を作る
> ための枠で、本ソフトウェアが使う API とは別の課金です）。API は**使った分だけの前払い方式**なので、
> **アカウントを作ったら $5 チャージしてください**（1日30往復なら約3週間、1日10往復なら約2か月もちます）。
> **残高が切れると声が出なくなります。**⚠️ チャージは返金されないので、少額から試してください。

### 🚀 セットアップ方法

1. **[MikuAgentSetup.exe をダウンロード](https://github.com/ChordDotE/watashinosekaito_hatsunemiku/releases/latest/download/MikuAgentSetup.exe)して実行**
    - [Releases](https://github.com/ChordDotE/watashinosekaito_hatsunemiku/releases) のページから取る場合は、各版の下の「Assets」にある `MikuAgentSetup.exe` を押します（緑の「Code」ボタンのダウンロードはソース一式で、インストールには使いません）
    - 署名の無いインストーラなので「WindowsによってPCが保護されました」と出ることがあります。そのときは「詳細情報」→「実行」を押してください
    - 途中で APIキー（Google AI Studio・Fish Audio）と Live2D 素材の zip 2つを求められます（上の「APIキーの取り方」）
    - ファイルを置いたあと、Python 環境・AIモデル・Live2D の構築に **10〜30分**かかります。その間も画面は動かしたり最小化したりでき、他のアプリも使えます
    - やめたいときは「キャンセル」（または ×）を押すと、インストール前の状態に戻ります
    - 終わるとデスクトップに「ワタシノセカイト初音ミク」のショートカットができます
2. コマンドから入れる場合（上級者向け）: インストーラを `/SILENT` で動かすか、`miku\setup_unattended.ps1` を直接呼べます（詳しくは [install_steps.md](install_steps.md)）

> **注意**: セットアップ・起動はすべて Windows 標準の PowerShell 5.1 で動作します（PowerShell 7 のインストールは不要）。

### 📖 使い方

#### 起動方法
1. デスクトップの「**ワタシノセカイト初音ミク**」ショートカットをダブルクリック
   - または `miku` フォルダ内の `start_miku.bat` をダブルクリック
2. **ミクのスタート画面**が開きます（起動・停止・設定・ログをここでまとめて扱います）
3. **「起動」ボタン**を押すと、必要なソフトがまとめて立ち上がります
4. 表示が「**🎤 動作中**」に変われば準備完了です（アクセス先のURLもここに出ます）。
   立ち上がるまで数十秒〜数分かかることがあります

> 💡 **記憶の整理をスキップしたいとき**: 「起動時に記憶の整理をスキップする」にチェックを入れてから
> 起動すると、前回の会話を長期記憶へまとめる処理を省いてすぐ話し始められます。

#### アクセス方法
- **PCから**: ブラウザで `http://localhost:5001` を開く
- **スマホから**: 同じWi-Fi内で `http://[PCのIPアドレス]:5001`
- **外出先から**: 外部アクセスを有効にした場合（セットアップのとき、または「設定」タブで切り替え）、
  起動するとスタート画面の「アクセス先」に出る外出先用のURLでアクセスできます
  （**セキュリティ上の注意があります**。[セキュリティ・プライバシー](#-セキュリティプライバシー)を必ずお読みください）
- **設定の変更・機能の追加**: **スタート画面の「設定」タブ**から行います（反映は再起動時。
  **システム停止中でも変更できます**）

**⚠️ 重要**: システム起動前からページを開いていた場合は、必ず起動後にブラウザでページをリロードしてください。

#### 基本操作
1. テキストボックスに話したいことを入力して「話す」— ミクが声で返事をしてくれます
2. **マイクボタン**: 1回押すと音声認識ON（文字起こしのみ）、もう1回で**自動送信モード**
   （話し終わると自動で送信され、手を使わず会話できます）。長押しすると
   直近の会話履歴とマイク感度の調整パネルが開きます
3. **カメラボタン**: カメラの映像をミクに見せながら話せます。ON のあいだ、ミクはあなたの顔の方を向きます
   （顔の位置はブラウザの中で調べ、そのための映像は外部に送りません）
4. 画像・音声・動画ファイルを添付して見せることもできます
5. ミクのボタンが「考え中（追加OK）」のときは、続けて話しかけてOK — まとめて踏まえて返事します

#### 🎯 ミクとの楽しい会話のコツ

### ❗ ミクが返事をしてくれないとき（エラーの調べ方）

ミクが「エラーが出てるみたい」と言ったときは、**画面に出ているコード**を見てください。
原因のほとんどは次のどれかです。

| コード | 何が起きているか | どうすればいいか |
|---|---|---|
| `payment_required`（402）| **Google のクレジット残高が空**です | [AI Studio のお支払いページ](https://aistudio.google.com/)で補充するか、オートチャージを設定してください。**補充するまで、待っても直りません** |
| `authentication`（401）<br>`permission_denied`（403）| **APIキーが違う・使えない** | スタート画面の「設定」タブで、Google AI Studio のキーを入れ直してください |
| `failed_precondition`（400）| **課金が有効になっていない** | AI Studio で請求先アカウントを設定してください |
| `rate_limit_exceeded`<br>`quota_exceeded`（429）| **一時的に上限**に達しています（無料枠でよく出ます）| 少し待つと戻ります。毎日出るようなら有料枠をご検討ください |
| `service_unavailable`（503）<br>`api_error`（500）| **Google 側が混み合っている** | 時間をおいて試してください |
| 上記以外 | — | スタート画面の**「ログ」タブ**に詳しい内容が出ています |

**もっと詳しく知りたいとき**: コードの一覧は Google の公式ページ
（https://ai.google.dev/gemini-api/docs/api-errors ）にあります。

#### どこで起きたかは、メッセージの先頭を見てください

エラーは**出どころ**がわかるように表示されます。原因の切り分けはここから始めてください。

| 先頭の表示 | どこの問題か | まず見るところ |
|---|---|---|
| `[Google AI Studio]` | **会話が作れない**（上の表） | AI Studio のクレジット残高・APIキー |
| `[Fish Audio]` | **声が作れない・聞き取れない** | [Fish Audio](https://fish.audio/) の残高とAPIキー（声だけ出ない・音声入力だけ効かない、という形で出ます）|
| `[本体]` | **このソフト側の不具合や、環境による問題** | スタート画面の「ログ」タブ |

#### それでも直らないときは

**よければ報告してください。**環境によっては、こちらで気づいていない不具合が出ることがあります
（個人で作っているものなので、必ず直せるとは限りません）。

### 🔧 終了方法

**スタート画面の「停止」ボタン**を押すだけです。関連するソフトもまとめて終了します。
その日の会話は次に起動したときにミクの記憶へ入るので、**停止のしかたで記憶が消えることはありません**。

| やりたいこと | 操作 |
|---|---|

### 🔒 セキュリティ・プライバシー

#### データの保存
- 会話履歴・記憶データ・設定は、すべて**お使いのPC内**に保存されます
- **顔と声の登録データ（写真・録音）**も、お使いのPC内に保存されます
- ファイルは暗号化されていません。PCへの物理的アクセスがある場合は内容を確認できます

- **インターネット上の楽譜・音源・歌詞**（作曲のカバー機能を使った場合のみ）: お手本となる
  楽譜（MIDI）や音源、歌詞を検索して自動的にダウンロードします（検索に DuckDuckGo などを使います）
- **Gmail**（メールの送信を設定した場合のみ）: ミクからのメールを送るため（メールの本文が送信されます）

## 第2章: 開発者向けガイド 🛠️

### 🤖 システム概要

**Pydantic AI** をエージェントフレームワークとして使用したマイクロサービス構成です。
Gateway がハブとなり、Agent（LLM）・TTS・KV（会話ログ）・VDB（長期記憶）・STT（音声認識）を
内部スレッドで駆動します。

```
Browser（チャットUI / Live2D iframe / マイク・カメラ / 音声出力）
    ↕ Socket.IO + REST
Gateway :5001  ← 全サービスのハブ（Flask + SocketIO・Agent をインプロセス駆動）
    ├─ Agent (Pydantic AI + Gemini)   LLM・記憶・ツール呼び出し
    ├─ 声（Gateway 内）               Fish Audio PCMストリーミング
    ├─ KV :8010                       会話ログ・状態
    ├─ VDB :8020                      長期記憶（Chroma + BM25 ハイブリッド検索）
    ├─ STT :5006                      リアルタイム音声認識（Fish Audio）+ 終話判定（Smart Turn v3）
    └─ Recognition :5007              顔・声の照合（マスター本人の特定）
```

主な設計上の特徴:
- **リアルタイム会話**: LLM のテキスト生成と並行して TTS へストリーミング（チャプター方式）。
  終話判定（Smart Turn）による即時応答、考え中の追加発話の畳み込み（進行中ターンへの時系列注入）
- **記憶**: 会話ログ（正式JSON）→ 定期的な長期記憶への整理（ベクトル+BM25 検索で想起）
- **自発的行動**: 無応答リマインダー・自由行動・自発的な話しかけのスケジューラ
- **スタート画面**: pywebview 製のネイティブパネル（起動・停止・設定・ログ）

### 🏗️ 技術スタック

```
Backend:     Python 3.13 + Flask + Flask-SocketIO + Pydantic AI（Google Gemini API）
Voice:       Fish Audio API（PCMストリーミング）
STT:         Fish Audio ASR ＋ Smart Turn v3（終話判定・ONNX）
Recognition: 顔（MTCNN + FaceNet）・声（話者照合）でマスター本人を特定
Frontend:    HTML5 + JavaScript（Web Components / AudioWorklet / ES Modules）
Live2D:      Cubism SDK for Web + TypeScript（利用者が素材を取得しローカルでビルド）
Storage:     KV Service（会話ログ・状態）/ Chroma（長期記憶・埋め込みは Gemini API）
Panel:       pywebview + WebView2（スタート画面）
Scripts:     PowerShell 5.1（セットアップ・起動）/ Inno Setup（インストーラ）
```

### 🔧 カスタマイズ

- **設定**: スタート画面の「設定」タブ（GUI・停止中でも編集可）または `src/settings.json`。
  音声モデル（voice_id）・音声入力の有無・各種機能の有効化などを変更できます
- **音声**: Fish Audio の voice_id を差し替えることで別の声にできます
- **プロンプト**: `src/agent/prompts/` 配下にキャラクター・応答のプロンプトがあります
  （改変は個人利用の範囲でどうぞ）
